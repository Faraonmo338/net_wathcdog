Назначение и интерфейс: Это легковесный скрипт для системного трея (возле часов), который работает в фоновом режиме через библиотеку pystray и в реальном времени отображает статус сети прямо во всплывающей подсказке иконки. 

Мониторинг соединения: Каждые 15 секунд скрипт отправляет легкий тестовый запрос к службе Cloudflare ([http://cp.cloudflare.com/generate_204](http://cp.cloudflare.com/generate_204)), чтобы проверить, есть ли реальный доступ в интернет. 

Аналитика трафика и потерь: С помощью библиотеки psutil скрипт замеряет скорость входящего трафика на ПК (автоматически переключая отображение из килобайтов в мегабайты), а также ведет скользящую историю из последних 10 проверок для расчета процента потерь пакетов (loss_pct). 

Двухуровневая система восстановления (Эскалация):

•	Сброс стека: Если пинг падает 3 раза подряд (failed_strikes >= 3), скрипт автоматически выполняет очистку и обновление сетевых интерфейсов через команды ipconfig /release, ipconfig /flushdns и ipconfig /renew. 

•	Перезагрузка роутера: Если первый шаг не помог и интернет все еще лежит, скрипт переходит на следующий уровень эскалации и запускает твой файл управления роутером (D:\Programs\Router\Router FireFox.py), после чего делает паузу на 80 секунд для восстановления оборудования.
